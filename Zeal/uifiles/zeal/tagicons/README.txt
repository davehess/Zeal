Guild tag pictures that ship with this Zeal build.

A picture here replaces the built-in shape for the same key:
  ^I<CODE>^  icon    <CODE>.png   (Continuum is ICON.png: Windows reserves the name CON)
  ^F<CODE>^  banner  F<CODE>.png
Players without these files see the built-in shape, or just the text.

To use your own picture instead, put it in the custom folder next to this file (tagicons\custom) with the same
name, then type /tag icons. Files in custom are never replaced by an update.

Each logo belongs to its guild. They were cut from the guilds' own logos at 128 pixels or less; the source
logos and the recipes that cut them are in the Wolf Pack platform repository
(docs/upstream/zeal-guild-icon-refresh/intake).
